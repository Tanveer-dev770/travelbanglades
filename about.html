ABOUT THE PLATFORM

Travel discovery,
with context.

Travel Bangladesh is designed around one idea: the best destination is not just popular — it is the place that makes sense for you today.

HOW IT WORKS

Weather. Distance. Interests.

The recommendation engine combines destination metadata with the current weather at each destination when available, your approximate distance, your selected interests and a popularity/rating signal. Each score is explainable rather than pretending to be an objective truth.

Weather suitability is deliberately simple: outdoor destinations get a boost in comfortable, dry conditions; indoor places are more resilient in rain. The engine can evolve as better metadata is added.

DATA & WEATHER

Transparent by design.

The initial destination catalog is a curated seed dataset, not a claim to include every attraction in Bangladesh. Coordinates and descriptive fields are stored separately from application logic so the catalog can grow to thousands of destinations later.

Live weather uses Open-Meteo's public forecast API in the browser, so there is no secret weather key in this repository. If you later choose a provider that requires a private credential, the included Vercel API pattern can be used as the secure boundary.

WEATHER_API_KEY

Only needed if you switch to a keyed weather provider. Store it in Vercel Environment Variables, never in Git.
